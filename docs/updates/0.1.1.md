## SimPilot EFB 0.1.1

- Added working map text sizing, a distance/bearing ruler, Low/High map detail and company traffic from VATSIM.
- Added Customization for appearance, accent and route colors, map labels, globe/grid options, chart night mode and startup preferences.
- Fixed the WX layer and added worldwide METAR/TAF indicators, SIGMET details, forecast offsets and an ATIS/weather briefing.
- Removed generated placeholder charts and the demo-flight option. Existing saved flight charts remain available.
- Fixed pending chart annotations being lost when switching pages quickly.
- Removed bouncing, pulsing and content transitions from the top bar.
- Added a PC bridge download that runs without installing Node.js, with an optional chart-panel installer.
- Improved bridge startup/shutdown, connection instructions, firewall troubleshooting and installer failure handling.

Live Windows/MSFS integration and physical iPadOS 15.3.1 checks remain pending.
