## SimPilot EFB 0.1.2

- Update the iPad app and PC bridge together. For this upgrade, extract the new **SimPilot-for-PC.zip** to get the matching SimPilot Link files. Enter the PC address and pairing code from the bridge window or console in **Settings → Bridge** on the iPad. The iPad connects over HTTPS on port 8387. SimPilot Link still connects locally on port 8386.
- Chart re-exports keep the last complete copy until the replacement is ready. If an export is interrupted, the previous pages remain in the cache.
- The Windows updater includes the matching SimPilot Link installer, repair files and setup guide.
- Route progress now follows the short leg across the international date line. Traffic is subscribed per iPad, CPDLC sends get distinct message IDs, and automatic landings match their flight in the logbook.
- Bridge downloads enforce size limits as data arrives.
